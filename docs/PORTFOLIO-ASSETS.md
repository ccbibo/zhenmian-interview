可用於規劃的虛構範例（不是通話實錄）：

- 面試官：「請介紹一個你做過的 AI 專案，說明你的責任。」
- 回答方式：問題背景 → 本人負責範圍 → 實作與測試 → 結果與限制。
- 追問方向：「你如何驗證回答有依據？遇到不同版本的文件怎麼處理？」
- 回顧方式：對照原回答，找出缺少證據與可補充經驗，再寫下次的回答筆記。

使用者真人驗收：肯定整體對話、流暢度、AI 整理面試紀錄與個人筆記體驗；不換算成未執行的十人評分。
